# 🕒 Time Utility App

A minimal and fast-loading web app that includes:

- 🌍 Dynamic Timezone Viewer
- 🔁 Time Converter (IST-based)
- ⏱️ Stopwatch
- ⏳ Timer with Reminder
- 🔘 Feature Toggle for all modules

Built with vanilla HTML, CSS, and JavaScript — no frameworks, no external libraries, no slowdowns.

---

## 🚀 Features

- Add any timezone (e.g. `America/New_York`, `Asia/Kolkata`)
- View current date and time per timezone (auto-updated every second)
- Convert time intervals from IST to added timezones
- Simple stopwatch with start, pause, and reset
- Countdown timer with custom duration and notification popup
- Toggle features on/off for a clean, personalized interface

---

## 🌐 Timezone Input
Please use valid IANA timezone format: `Region/City`

📘 [Reference List of Timezones](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones)

---

## 📁 Usage

1. Clone or download this repository
2. Open `index.html` in any browser
3. No installation or server required
