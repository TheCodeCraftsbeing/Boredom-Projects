# 🔍 JSON/Text Compare Tool

A simple, lightweight, front-end-only **side-by-side diff tool** to compare two text blocks or JSON files.  
Perfect for developers who need a quick way to compare inputs — no backend or file upload required.

## ✨ Features

- ✅ Compare two files: JSON or plain text
- ✅ Toggle: “Treat input as JSON?”
- ✅ Highlights:
  - 🟩 Green → Same lines
  - 🟥 Red → Different lines
- ✅ Line numbers for reference
- ✅ Scroll sync between panels
- ✅ Fully client-side — fast and secure

---

## 🚀 How to Use

1. **Paste** your content in the left and right text areas.
2. Toggle `Treat input as JSON?` if comparing JSON.
3. Click **Compare**.
4. View the side-by-side comparison with colored highlights.
